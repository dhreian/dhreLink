# Changelog

Los cambios importantes de dhreLink se documentan en este archivo.

## 1.0.0 — 2026-09-02

- Publicación inicial estable para Windows x64.
- Emisor VST3 transparente con interfaz compacta y fuentes integradas.
- Receptor de audio para OBS Studio con estado de conexión e icono propio.
- Reconexión automática cuando el emisor se añade, elimina o reinicia.
- Instalador único con verificación de integridad y desinstalación completa.
